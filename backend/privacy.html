隐私政策

凯旋智聘（浏览器扩展）· 生效日期：2026 年 7 月 29 日

本隐私政策说明「凯旋智聘」浏览器扩展（下称“本扩展”）如何收集、使用、存储和保护信息。 在首次登录及启用自动化任务前，本扩展会展示数据处理说明并取得用户的主动确认。

一、我们收集哪些信息

  • 账号信息：您注册/登录时提供的电子邮箱地址，以及用于登录的验证码。用于身份验证和账号管理。
  • 订阅信息：您的会员状态、套餐类型、到期时间，用于提供付费功能。
  • 候选人与招聘信息：为提供简历采集、简历打分、岗位匹配和沟通辅助功能，本扩展会在用户主动启用相应任务后， 读取当前招聘页面上的候选人姓名、联系方式、简历文本、岗位信息及聊天内容。用户应确保自己有权处理这些招聘信息。
  • AI 功能运行数据：启用 AI 回复、简历解析或简历打分时，必要的简历文本、岗位信息或聊天内容会发送给用户配置的第三方大模型服务进行处理。 这些内容仅在处理当次请求时使用，不在我们的服务器上留存。
  • 账号云端配置：登录后，岗位、话术、拟人频率、定时任务、回复规则、知识库、大模型名称与接口地址、简历采集及回复设置会默认与账号云端同步， 用于在该账号登录的设备上继承配置。用户填写的大模型 API Key 不上传服务器，仍仅保存在当前设备。
  • 本地人才库：候选人整理结果和人才库默认保存在用户的浏览器本地，不随普通账号配置上传。 仅当用户在人才卡片上主动确认“提交呼波特”时，所选候选人的姓名、电话、岗位、岗位 JD、确认事项、特殊说明和使用人员才会上传到我们的服务器并转交呼波特处理。
  • 初面反馈：呼波特完成用户明确提交的电话初面后，会向我们的服务器回传与该候选人关联的话单状态、呼叫时间与时长、通话摘要、 意向判断、加微状态、聊天记录及录音地址，并在插件的“初面反馈”独立面板中展示。
  • 授权记录：本扩展会在浏览器本地保存隐私政策版本、确认时间及自动化任务范围，用于证明任务由用户主动授权。

二、我们如何使用这些信息

  • 验证身份、维护登录状态与账号安全。
  • 提供并管理会员订阅与付费功能。
  • 按登录账号保存并同步用户的招聘配置，使同一账号在不同设备继承岗位、话术与自动化参数。
  • 实现简历打分、自动/辅助回复等核心功能。
  • 在用户逐条主动确认后，把指定人才线索提交到呼波特项目，并在独立的“初面反馈”面板中关联展示后续电话话单结果。
  • 按照用户确认的岗位、话术来源、候选人范围和运行时间执行招聘辅助任务。

三、信息的共享

我们不出售您的个人信息。仅在以下必要情形共享：

  • 第三方大模型服务：当用户启用 AI 功能时，相关文本会发送给用户自行配置的大模型服务商 （如 OpenAI、DeepSeek 等）进行处理。该处理受各服务商自身隐私政策约束。您可自行选择使用哪家服务。
  • 呼波特线索处理服务：仅当用户在人才库逐条确认提交时，指定候选人的姓名、电话、岗位及招聘备注会发送至呼波特， 用于用户明确请求的线索处理、沟通及结果回传。呼波特项目 Token 和渠道密钥只保存在我们的后端，不会写入浏览器扩展。
  • 法律要求：在法律法规要求或为保护合法权益的必要范围内。

四、信息的存储与安全

  • 邮箱、订阅及账号云端配置存储在我们的服务器，通过 HTTPS 加密传输；云端配置采用修订号控制，降低旧设备覆盖新配置的风险。
  • 登录凭证（令牌）采用行业通用的加密签名方式。
  • 完整简历正文和招聘平台原始聊天内容不在我们的服务器落库，处理后即丢弃；用户主动提交呼波特的结构化人才字段， 以及呼波特为该次电话初面返回的话单、摘要、意向判断、通话聊天记录和录音地址会在服务器保留，以便关联和展示“初面反馈”。
  • 大模型 API Key、人才库、设备标识、隐私授权和自动化运行状态仅存于当前浏览器，不进入账号云端配置；卸载扩展会清除这些本地数据。
  • 本扩展只将数据用于用户可见的招聘辅助功能，不出售数据，不将数据用于个性化广告，也不允许工作人员在未经授权的情况下查看候选人内容。

五、数据保留与您的权利

  • 账号、订阅和云端配置在您使用期间保留；您可要求查询或删除您的账号及相关数据。
  • 您可随时停止使用并卸载本扩展，本地数据将被清除。
  • 如需删除服务器上的账号数据，请通过下方邮箱联系我们。

六、未成年人

本扩展面向招聘从业者，不面向未满 18 周岁的未成年人，我们不会主动收集未成年人信息。

七、政策更新

我们可能不时更新本政策，更新后将修改页面顶部的"生效日期"。重大变更会通过适当方式告知。

八、Chrome Web Store 有限使用声明

本扩展对用户数据的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。数据仅用于提供或改进用户明确请求的招聘辅助功能，不用于与该单一用途无关的目的。
